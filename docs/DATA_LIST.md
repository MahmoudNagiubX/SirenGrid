**Status:** 🔒 LOCKED

**MVP Geography:** Nasr City, Cairo  
**Primary Demo Corridor:** Rabaa → Tayaran Street → Abbas El Akkad → Makram Ebeid → El Nasr Road

---

## 1. Purpose

This document defines the **final data sources** approved for the SirenGrid MVP.

Every important data item must be clearly classified as one of the following:

- **REAL PUBLIC** — public/geospatial/static data from open or official sources.
- **REAL LIVE** — live external data retrieved from a real provider.
- **REAL / DERIVED** — processed data created from real public sources.
- **SYNTHETIC / TEAM-CREATED** — evaluation data generated by the team.
- **SIMULATED OPERATIONAL DATA** — operational state that would normally require a real government, emergency-service, hospital, telecom, or traffic-control integration.

**Important rule:** Simulated data must never be presented as official or live data.

# 6. Required Provenance Metadata

Every important dynamic or operational record should store at minimum:

```json
{
  "source": "TomTom / OSM / MOHP / SIMULATION / etc.",
  "data_reality": "REAL_PUBLIC | REAL_LIVE | REAL_DERIVED | SIMULATED | SYNTHETIC",
  "last_updated": "ISO-8601 timestamp",
  "freshness_status": "LIVE | FRESH | STALE | STATIC",
  "source_reference": "URL or internal dataset identifier"
}
```

This is important because SirenGrid must never make simulated data appear to be official live operational data.

Egyptian-ASR-MGB-3 + SirenGrid team-created emergency-call set
